# Directorio Web

MVP de una plataforma de mini-páginas web para negocios.

## Stack

- Vite
- JavaScript modular
- Tailwind CSS
- Lucide
- Datos locales

## Instalación

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

La carpeta de producción es `dist`.

## Netlify

- Build command: `npm run build`
- Publish directory: `dist`

El archivo `netlify.toml` ya incluye el redirect SPA.
